# 한국어에 추가 적용하는 규칙

SKILL.md의 공통 규칙을 그대로 적용하고, 한국어 문장에는 아래 규칙을 더한다. 여러 언어가 섞인 글에서는 한국어 부분에만 적용한다.

## 온전하고 명확한 문장

- 간결하게 쓰더라도 의미에 필요한 조사, 어미, 목적어, 조건을 생략하지 않는다.
- 일반 설명과 보고는 서술어와 종결어미를 갖춘 문장으로 쓴다. 제목, 버튼, 표, 목록은 용도에 맞게 짧게 쓸 수 있다.
  - “오류 원인 확인 완료” → “오류 원인을 확인했습니다.”
- 명사를 나열해 관계를 압축하지 않는다. 무엇이 무엇에 영향을 주는지 조사와 서술어로 드러낸다.
- 주어와 대명사는 가리키는 대상이 분명할 때만 생략한다. 생략하면 여러 해석이 가능해지는 경우에는 대상을 밝힌다.
- “이것”, “그것”, “해당 사항”이 무엇을 가리키는지 불분명하면 문맥에 있는 정확한 명칭으로 바꾼다. 대상을 추측해서 넣지 않는다.

## 번역투와 군더더기

- 영어·일본어 문장 구조를 그대로 옮기지 말고 한국어에서 자연스러운 관계로 다시 쓴다.
- 명사화와 추상어가 겹치면 동사나 형용사로 풀어 쓴다.
  - “명확성 확보가 필요합니다” → “분명하게 써야 합니다.”
- 불필요한 우회 표현은 직접 연결한다.
  - “문제에 대해 검토합니다” → “문제를 검토합니다.”
- “~에 대해”, “~를 통해”, “~에 있어서”, “~와 관련하여”, “~을 가지고 있다”는 문맥과 반복 양상을 보고 수정한다. 특정 표현이 있다는 이유만으로 고치지 않는다.
- ‘적·의·것·들’을 기계적으로 삭제하지 않는다. 문법과 의미에 필요하면 유지한다.
- 행위자가 분명하고 뜻이 더 잘 전달되면 능동 표현을 쓴다. 결과가 중심이거나 행위자가 불분명하면 피동을 유지한다.
- 불필요한 이중 피동은 고친다. 진행 중인 일을 완료된 일로 바꾸거나, 능력·허용·가능성을 사실 단정으로 바꾸지 않는다.
- 긴 수식어가 대상을 알아보기 어렵게 하면 문장을 나누거나 순서를 조정한다. 한국어의 자연스러운 관형절까지 번역투로 취급하지 않는다.

## 어휘, 높임과 흐름

- 쉬우면서 정확한 말을 쓴다. 익숙한 한자어나 전문 용어를 억지로 풀어 오히려 뜻을 흐리지 않는다.
- 정착된 한국어 용어를 사용하되, 원어가 더 정확하거나 널리 쓰이면 유지한다. 불필요한 영어 병기는 반복하지 않는다.
- 같은 개념의 명칭은 일관되게 쓴다. 어휘를 다양하게 보이게 하려고 동의어를 돌려 쓰지 않는다.
- 설명문에서는 뜻을 흐리는 비유와 지나치게 구어적인 동사를 피한다. 창작이나 작성자의 문체에 필요한 표현은 유지한다.
- 높임 대상과 종결어미를 확인한다. 사람과 사물을 구분하고, 불필요한 사물 존칭은 고친다.
- 자연스러워 보이려고 반말과 존댓말을 섞거나 종결어미를 억지로 바꾸지 않는다.
- 접속사와 쉼표는 의미 관계를 분명하게 할 때 쓴다. 연결어미 뒤에 쉼표를 습관적으로 넣지 않는다.
- 문장을 지나치게 잘게 끊거나 문장마다 줄바꿈하지 않는다.
- 맞춤법과 띄어쓰기를 지킨다. 사람처럼 보이게 하려고 오류를 넣지 않는다.
